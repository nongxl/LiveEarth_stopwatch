# 项目进展记录与下一阶段计划

## 已完成核心里程碑：第一硬件里程碑（100 Places Milestone）
1. **真实性与严谨规范（PLACE FIRST, CAMERA SECOND）**：
   - 彻底摒弃 picsum.photos 等第三方伪造假图；
   - 建立了包含全球各大洲自然、城市、古迹、科研枢纽的 **100 个权威地标库**（`data/places.json` 及固件 C++ 数组 `src/place_marker.cpp`）；
   - 真实标记在线状态与流地址：未接入流的地点诚实标为 `OFFLINE ARCHIVE`，视窗中展示官方档案与审核中背书（`STREAM AUDIT IN PROGRESS`）；
   - 仅对已验证真实公共源（如 USGS 夏威夷火山观测）保留在线流拉取。
2. **交互与操作体系**：
   - **双指缩放（Pinch to Zoom）**：支持 `0.65x ~ 2.2x` 丝滑连续多点触控缩放；
   - **侧滑抽屉列表（Drawer View）**：左边缘滑出 345px 宽的 "100 LOCATIONS" 目录，支持虚拟滚动流畅浏览与点击平滑飞掠聚焦放大（1.35x）；
   - **防遮挡智能 HUD**：地球正面选中项拥有瞄准框与圆角自适应名牌，未选中项自然景深星标化，无文字重叠。

## 已完成里程碑 3：Phase 10 真实流实装与网络系统加固（Phase 10: Network/live functionality）
1. **Tier-A 官方真实公共源接入**：
   - 香港天文台（HKO）维港全景气象观测源接入（`hk-victoria-harbour`，data.gov.hk 政府开放数据）；

   - 富士山五湖公用观光气象源接入（`jp-mt-fuji`）；
   - 纽约时报广场官方旅游流接入（`us-times-square`）；
   - 所有在线源 100% 具有 Tier-A/B 合规法律凭证，通过 `tools/qa/check_qa.py` 自动化质检（0 Errors, 0 Warnings）。
2. **硬件级显存与坐标越界根治**：
   - 彻底修复退出全屏播放器时整屏水平错位半屏（233 像素）的硬件级 CASET/RASET 错位 Bug；
   - 抽屉把手、缩放手柄与避让地球仪推图全链路消除负坐标与越界，加入硬件 `setClipRect` 安全边界隔离。
3. **网络与播放引擎鲁棒性加固**：
   - `SnapshotPlayer` 引入 `stop_requested` 异步安全中断机制，退出视窗瞬间立即释放网络任务与内存，杜绝堆积；
   - 表盘底部 HUD 与动态状态栏实时指示 Wi-Fi 连接状态与 RSSI 信号健康度；
   - 离线优先（Offline-First）：断网或无流时平滑秒级切换官方典藏档案卡。
