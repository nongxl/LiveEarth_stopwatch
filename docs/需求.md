你现在负责开发一个完整的嵌入式开源项目：

PROJECT NAME:
LiveEarth

TARGET DEVICE:
M5Stack Stopwatch

CORE IDEA:
把全球合法公开的真实世界 Webcam 组织成一个可以通过圆形触摸屏探索的交互式 3D 地球仪。

用户不是通过传统列表寻找摄像头，而是：
旋转地球 → 发现地点 → 点击地点 → 查看地点介绍 → 查看实时 Webcam。

==================================================
0. DEVELOPMENT PHILOSOPHY
==================================================

这是一个真实的工程项目，不是 Demo。

必须优先考虑：

- 可维护性
- 数据质量
- 数据来源可追溯
- 合法公开来源
- RAM/Flash 限制
- 离线可用
- 可靠错误处理
- 模块化
- 后续自动数据更新
- 人工审核流程

不要为了“看起来完成”而硬编码大量临时数据。

不要伪造数据。

不要把未知信息猜测成事实。

如果一个数据无法可靠验证，应标记为 REVIEW_REQUIRED，而不是自行补全。

==================================================
1. PROJECT GOAL
==================================================

构建：

LIVE EARTH

一个运行在 M5Stack Stopwatch 上的互动式全球 Webcam 地球仪。

主要体验：

1. 用户看到 3D Earth
2. 地球表面显示真实地点的 Live Camera markers
3. 用户通过触摸旋转地球
4. 点击 marker
5. 查看地点名称、国家、简介、分类
6. 查看该地点拥有的 Webcam
7. 如果存在合法且可用的 live source，则进入 Live View

核心原则：

PLACE FIRST
CAMERA SECOND

==================================================
2. LEGAL DATA POLICY
==================================================

这是硬性要求。

禁止将：

- Shodan 扫描结果
- Censys 扫描结果
- 默认密码摄像头
- 匿名 IP camera
- 未知私人 CCTV
- 暴露 RTSP
- 未授权监控设备

作为生产数据源。

“可以从 Internet 访问”绝不等于“允许重新发布”。

允许优先发现：

TIER A:
- Government
- National Park
- Tourism Board
- Weather Agency
- Observatory
- Airport
- Port
- Ski Resort
- Zoo
- University
- Official Destination Operator

TIER B:
明确声明为 Public Webcam / Live Webcam 的运营方。

TIER C:
具有明确开放数据/API/license 的来源。

TIER D:
第三方 Webcam 聚合网站。

Tier D 可以用于发现地点和线索，但不能自动视为允许重新发布视频。

必须区分：

PUBLICLY VIEWABLE

和：

REDISTRIBUTION / EMBEDDING PERMITTED

如果无法确定后者：

permission_status = REVIEW_REQUIRED

绝不能自行推断为 APPROVED。

==================================================
5. DISCOVERY STRATEGY
==================================================

优先搜索官方来源。

搜索策略应包括：

"[place] official webcam"
"[place] live camera"
"[place] tourism webcam"
"[place] public webcam"
"[organization] webcam"

不要只依赖搜索结果。

对于第三方 Webcam 网站发现的地点：

1. 提取地点
2. 搜索官方来源
3. 验证官方来源
4. 判断是否可以使用
5. 只有通过审核后进入 production
